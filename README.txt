SMART EXPENSE TRACKER — WEBSITE DEMO

HOW TO RUN
1. Extract the ZIP file (if using the ZIP).
2. Open index.html in Chrome, Edge, or another modern browser.
3. Set your monthly budget, then choose "Add new expense".
4. Try search, delete, CSV export, and reset.

FEATURES
- Black-and-gold responsive dashboard
- Monthly budget and remaining amount
- Add expenses with category, date, and amount
- Recent activity and full expense list
- Search, delete, CSV export
- Saves demo data in browser localStorage

PROJECT NOTE
This is a browser-based front-end inspired by the supplied C program. It is not compiled C code and does not connect to a server. The original C code remains the console implementation.
